⚙️ Backend Engineering Workplan

Team Size: 2 Coders

Goal: Build a robust, zero-dependency Python backend that handles auth, sessions, and serves data efficiently.

🛠 Tools & Tech Stack

  • Language: Python 3 (Standard Library only - http.server, json, uuid)
  • IDE: VS Code or Cursor
  • API Testing: Postman, Insomnia, or Terminal curl
  • Version Control: Git / GitHub
  • Collaboration: Live Share (VS Code extension) to code together in the same file.

📁 Files to Create

You only need a few files, but keep the code organized:

  • serve.py (The main HTTP server and request handler)
  • api_auth.py (Optional: If serve.py gets too long, put login/register logic here)
  • api_data.py (Optional: Logic for reading/serving the hospital JSON)
  • logs/server.log (For debugging API calls during the hackathon)

👨‍💻 Work Division (How to split the 2 coders)

🧑‍💻 Backend Coder 1: "The Data & Router Engineer"

Focus: Server infrastructure and data delivery.

  • Hour 1: Write the base serve.py using http.server.SimpleHTTPRequestHandler. Ensure it serves files from the public/ folder correctly.
  • Hour 2: Build the API router logic (the do_GET and do_POST overrides that intercept /api/* paths).
  • Hour 3: Build the GET /api/hospitals endpoint. Work with the Data/Maths person to load their JSON file into memory and serve it.
  • Hour 4-5: Add HTTP headers for caching (Cache-Control) and CORS (Access-Control-Allow-Origin: *) so the frontend doesn't get blocked. Add error handling (try/except blocks) so the server doesn't crash if bad data is sent.

🧑‍💻 Backend Coder 2: "The Auth & Security Engineer"

Focus: Sessions, cookies, and user management.

  • Hour 1-2: Design the in-memory data structures (USERS = {} and SESSIONS = {}). Pre-seed the demo account (akansh / admin123).
  • Hour 3: Build POST /api/login and POST /api/register. Generate UUIDs for sessions.
  • Hour 4: Master HTTP Cookies. Make sure the login API sends the Set-Cookie header properly (HttpOnly, Path=/).
  • Hour 5: Build GET /api/session (to check if a cookie is valid) and GET /api/logout (to destroy the session).

⚠️ Critical Checkpoints for Backend

1. The "No-Crash" Rule: During the demo, if the frontend sends a malformed JSON, your backend must return a 400 Bad Request, not throw a Python KeyError and crash the server. Wrap your JSON parsing in try/except.
2. Sync with Frontend: By Hour 3, Frontend Coder 2 will need your /api/login endpoint. Ensure you agree on the exact JSON format (e.g., {"username": "...", "password": "..."}).
3. Log Everything: Override log_message in serve.py to print every API call to the terminal. If a bug happens during the hackathon, you need to see exactly what the frontend requested.
